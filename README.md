📊 CheckDailyReports (v1.1.0)

Excel形式の日報ファイルの入力ミスを自動チェックするデスクトップアプリケーションです。

指定した複数フォルダ内のすべてのサブフォルダから、日報ファイル（.xlsx, .xlsm）を走査して入力間違いやテンプレートの破損を自動的にチェック・一覧表示します。

⚠️ 安全性について

本アプリは日報ファイルを読み込むだけであり、ファイルを上書き保存・変更・編集することは絶対にありません。安全にご使用いただけます。

✨ 主な機能と特徴

📁 複数フォルダの一括チェック対応

チェック対象のフォルダをリストに複数登録可能。配下にあるすべてのフォルダを自動的に探索し、日報ファイルを漏れなく確認します。

🛡️ 多彩な自動検証ルール

チェック項目は「設定」から自由にオン・オフが可能です。

氏名・日付等スマートスキャン

氏名や日付の記入漏れ、日付フォーマットの間違い

作業時間の未入力、負の工数、過大時間（24時間超など）の入力

管理No未入力チェック

作業実績（工数）が入力されているのに、管理Noが未入力の箇所を検出

コード未入力チェック

管理Noが設定されているのに、型枠コードや作業コードが未入力の箇所を検出

数値フォーマットチェック

数値が必須のエリアに、空白や文字列が入力されている箇所を検出

勤務時間単位チェック

端数時間の入力エラーを検出（例：60分単位での入力ルール違反など。倍数は設定で変更可能）

基準テンプレート不整合チェック

基準となるテンプレートファイルを指定することで、入力セル以外の「固定文字列」や「数式」が誤って書き換えられていないかを比較・検出

🔍 便利な結果フィルターと詳細表示

検出されたエラーは一覧で表示され、「エラー区分」ごとの絞り込みや「キーワード検索」が可能です。
さらに、リスト上のエラー項目をダブルクリックすることで、詳細な原因を別ウィンドウで確認できます。

🚀 基本的な使い方

アプリケーション（CheckDailyReports-v1.1.0.exe）を起動します。

「1. 対象フォルダ選択」の「追加 (＋)」ボタンを押し、日報ファイルが保存されているフォルダを登録します（複数登録可）。

（任意）「2. 基準テンプレートファイル選択」で、比較元となる大元のExcelファイルを指定します。

「チェック開始」ボタンを押すと、自動チェックが始まります。

進捗バーとともにスキャンが進み、エラーが見つかるとリアルタイムにリストに追加されます。

リスト上のエラー項目をダブルクリックすると、詳細情報をポップアップで確認できます。

⚠️ セキュリティ警告が出た場合 (Windows SmartScreen)

アプリの初回実行時に、Windows Defender SmartScreenによって以下の警告画面が表示される場合があります。

「Windows によって PC が保護されました」
Windows Defender SmartScreen は認識されないアプリの起動を停止しました。

✅ 回避・実行の手順

警告画面内の 「詳細情報」 という青いテキストをクリックします。

開発元やアプリ情報の下に表示される 「実行」 ボタンをクリックします。

これにより、アプリが安全に起動されます（次回以降はこの警告は表示されません）。
