CheckDailyReports-v1.0.0

Excel形式の日報ファイルの入力ミスを自動チェックするデスクトップアプリケーションです。
指定したフォルダ内のすべてのサブフォルダから、日報ファイル（.xls, .xlsx, .xlsm）を走査して入力間違いを自動的にチェック・一覧表示します。

※本アプリは日報ファイルを読み込むだけであり、ファイルを上書き保存・変更・編集することは絶対にありません。安全にご使用いただけます。

主な機能と特徴

一括サブフォルダチェック

選択したフォルダの配下にあるすべてのフォルダを自動的に探索し、日報ファイルを漏れなく確認します。

スマートスキャン型検証ルール

ファイルのレイアウト形式に左右されにくくするため、「氏名」「日付」「時間」「工数」などのキーワード周辺を探索して自動的にルール適合確認を行います。

氏名や日付の記入漏れ、日付フォーマットの間違い、作業時間の未入力、負の工数入力、過大時間（24時間超など）の入力などを厳密に検出します。

安全第一のリードオンリー設計

Excelファイルを開く際は、リードオンリーモード（読込専用）で実行します。元のデータが書き換わることはありません。

詳細ダブルクリック機能

エラー検出リストをダブルクリックすることで、詳細な原因や修正推奨内容を別ウィンドウで確認できます。

使い方

アプリケーション（CheckDailyReports-v1.0.0）を起動します。

「1. 対象フォルダ選択」の「参照...」ボタンを押し、日報ファイルが保存されているフォルダを選択します。

「チェック開始」ボタンを押すと、自動チェックが始まります。

進捗バーとともにスキャンが進み、エラーが見つかるとリアルタイムにリストに追加されます。

リスト上のエラー項目をダブルクリックすると、詳細情報をポップアップで確認できます。

動作環境

Windows 10 / 11

Windows SmartScreenによるセキュリティ警告が出た場合の対処方法

アプリの初回実行時（特に独自でビルドしたexeファイルを使用時）に、Windows Defender SmartScreenによって以下の警告画面が表示される場合があります。

「Windows によって PC が保護されました」 > Windows Defender SmartScreen は認識されないアプリの起動を停止しました。

回避・実行の手順

警告画面内の「詳細情報」という青いリンクテキストをクリックします。

開発元やアプリ情報の下に「実行」というボタンが表示されます。

「実行」ボタンをクリックすることで、アプリが安全に起動されます（次回以降はこの警告は表示されません）。
